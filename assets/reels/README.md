# Reels

Drop vertical (9:16) videos here and point a slot's `src` at the file in
`app/work.jsx` → `REEL_TRACKS`.

Expected names for the slots that exist today:

  followup.mp4    AI Follow-Up for Realtors
  medspa.mp4      Med Spa Booking Funnel
  dispatch.mp4    Home Services Dispatch
  dashboard.mp4   Client Ops Dashboard

Format: MP4 (H.264 + AAC), 1080×1920, under ~8 MB each so the page stays quick.
A slot whose file is missing shows a "Reel coming soon" frame — it never breaks
the page, so you can add them one at a time.
